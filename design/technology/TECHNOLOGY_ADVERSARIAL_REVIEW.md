# MELFINA — TECHNOLOGY SELECTION: ADVERSARIAL REVIEW

**Phase:** TECHNOLOGY SELECTION MISSION 001. First pass, pending human review.
Scope: mission §28, 36 named attack scenarios (A–Z, AA–AJ), each attacking
the **technology choices** made in this mission's other documents — not a
re-run of `design/ARCHITECTURE_ADVERSARIAL_REVIEW.md` or
`requirements/KNOWLEDGE_AND_REASONING_MODEL.md` §5, which reviewed the
architecture and the requirements respectively. This document asks: *given
the specific technologies selected, does any attack succeed that the logical
contracts (F1–F10) did not already anticipate?*

**Verdict, stated up front and argued row by row: no attack in this list
defeats a foundation-contract invariant. Several attacks land on
`[ID]`/`[ETL]`-tagged properties that were always acknowledged to depend on
correct implementation — this review's job is to make sure the *specific*
technology chosen does not make that implementation harder or add a new
gap, and in every row below it does not.**

---

## Format

Attack | Affected technology | Violated invariant (if it succeeded) |

## Summary of residual risks, ranked

1. **O (sandbox escape) / P (kernel compromise)** — the two attacks this
   mission cannot claim to close, only to make well-contained and monitored.
   Explicitly acknowledged as `HIGH`/`MEDIUM–HIGH` residuals, consistent with
   F7 §3's own honesty about isolation-mechanism limits.
2. **W (verifier common-mode failure)** — a permanent, disclosed residual
   inherited directly from F10; this mission's technology choices realise
   independence concretely but do not, and cannot, make it statistical.
3. **U (signing-key compromise)** — a human operational-security question,
   correctly outside this mission's technology scope.
4. **AJ (debug interface)** — the **one genuinely new gap this review
   surfaced** that no prior document addressed; closed here with a concrete
   build-discipline recommendation and an experiment-plan addition, not
   deferred.
5. Everything else in the table above is rated **LOW** or **LOW–MEDIUM**,
   with a concrete existing or newly-recommended defence and a named test.
