# research/

Deep-research findings: surveys of prior art, comparisons, source notes,
open questions. Raw material for later phases.

**Belongs here:** literature and system surveys, notes on existing tools
(PIMs, PKMs, task systems, journaling systems, calendars), data-model
comparisons, storage-format research, cited sources.

**Does not belong here:** the user's own requirements (`requirements/`),
design decisions (`decisions/`), or the life model itself (`model/`).

Nothing starts here until the user issues the research mission.
