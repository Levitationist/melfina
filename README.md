# MELFINA

A research-first effort to build a lightweight, local-first personal life
operating system, shaped around one user's real needs rather than a generic
productivity method.

**Status:** deep-research phase (RESEARCH MISSION 001) in progress. No
application code. Read [`PROJECT_STATE.md`](PROJECT_STATE.md) first — it is the
source of truth for the current phase, principles, and layout.
