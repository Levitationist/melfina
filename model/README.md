# model/

The human / central life model: the small set of core abstractions the whole
system is built on (what a session, an artifact, a commitment, a thread of work,
a note, a reference actually are — names TBD).

**Belongs here:** the conceptual model and its vocabulary, entity/relationship
thinking, how music and creative practice fall out of the general abstractions.

**Does not belong here:** file formats, schemas, or code — those are `design/`
and `src/`.

Constraint: music is a *case* of the model, not a feature beside it.
